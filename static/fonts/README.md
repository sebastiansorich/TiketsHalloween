# Fuentes para el proyecto

## 🎃 Fuentes de Terror/Halloween (RECOMENDADAS)

Para que el ticket se parezca al arte oficial de la fiesta con estilo terrorífico, descarga una de estas fuentes gratuitas:

### Opción 1: Creepster (Google Fonts) - ⭐ RECOMENDADA

1. Ve a [Google Fonts - Creepster](https://fonts.google.com/specimen/Creepster)
2. Haz clic en "Download family"
3. Descomprime el archivo ZIP
4. Copia `Creepster-Regular.ttf` a esta carpeta
5. Renombra el archivo a `Horror.ttf`

### Opción 2: Nosifer (Estilo sangre goteando)

1. Ve a [Google Fonts - Nosifer](https://fonts.google.com/specimen/Nosifer)
2. Descarga y copia `Nosifer-Regular.ttf` a esta carpeta
3. Renombra a `Horror.ttf`

### Opción 3: Butcherman

1. Ve a [Google Fonts - Butcherman](https://fonts.google.com/specimen/Butcherman)
2. Descarga y copia `Butcherman-Regular.ttf`
3. Renombra a `Horror.ttf`

### Opción 4: DaFont (Muchas opciones)

1. Ve a [DaFont - Horror](https://www.dafont.com/es/theme.php?cat=110)
2. Busca fuentes gratuitas de terror
3. Descarga la que más te guste
4. Copia el archivo .ttf a esta carpeta
5. Renombra a `Horror.ttf`

## Fuentes actuales en el proyecto

- ✅ `Arial.ttf` - Fuente estándar
- ✅ `Arial-Bold.ttf` - Fuente más gruesa (Arial Black)
- ⚠️ `Horror.ttf` - **¡AGREGA ESTA!** Para estilo terrorífico
- ⚠️ `Creepster.ttf` - Alternativa de terror

## Verificación

Después de agregar la fuente, el sistema la cargará automáticamente.
Los logs mostrarán: "✓ Fuente cargada: [ruta]"
